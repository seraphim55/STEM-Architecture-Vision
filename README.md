# Низькорівнева обробка та контурний аналіз зображень архітектурних об'єктів

Проєкт присвячений реалізації класичних алгоритмів цифрової обробки зображень (Digital Image Processing) на низькому рівні засобами Python та матричних обчислень NumPy без використання високорівневих бібліотек комп'ютерного зору (OpenCV).

## Структура проєкту

    STEM-Architecture-Vision/
    ├── dataset/                  # Вхідна вибірка (120 зображень архітектурних об'єктів, 256x256)
    ├── output/                   # Результати роботи конвеєрів
    │   ├── samples/              # Візуальні порівняння (Оригінал | Пайплайн 1 | Пайплайн 2)
    │   ├── metrics_report.csv    # Повна таблиця метрик для кожного зображення
    │   └── metrics_telemetry_plots.png
    ├── src/                      # Ядро алгоритмів обробки та оцінки якості
    │   ├── __init__.py
    │   ├── filters.py            # Колірні перетворення, 2D-згортка, фільтри та порогова бінаризація
    │   └── metrics.py            # Обчислення MSE, PSNR та SSIM
    ├── tests/                    # Модульні тести (Unit Tests)
    │   └── test_pipeline.py
    ├── config.json               # Параметри фільтрів та шляхи директорій
    ├── download_dataset.py       # Скрипт автоматичного збору вибірки через API Wikimedia Commons
    ├── main.py                   # Головний скрипт пакетної обробки та побудови графіків
    └── requirements.txt          # Залежності проєкту

## Опис конвеєрів обробки

1. **Пайплайн 1 (Покращення контрасту та приглушення шуму):**
   * Перетворення RGB у напівтонове зображення за стандартом ITU-R BT.601 ($Y = 0.299R + 0.587G + 0.114B$).
   * Медіанна фільтрація ($3 \times 3$) для усунення імпульсного шуму зі збереженням чітких границь фасадів.
   * Еквалізація гістограми через кумулятивну функцію розподілу (CDF) для вирівнювання освітленості тіньових ділянок.

2. **Пайплайн 2 (Виділення структурних контурів):**
   * Виділення зеленого спектрального каналу ($G$), який має найвищу чутливість до деталей архітектурних поверхонь.
   * Гаусове згладжування ($5 \times 5$, $\sigma = 1.4$) через дискретну 2D-згортку для приглушення дрібної текстури цегли та штукатурки.
   * Обчислення градієнта яскравості оператором Собеля ($G = \sqrt{G_x^2 + G_y^2}$).
   * Автоматична порогова бінаризація методом Оцу (максимізація міжкласової дисперсії).

## Встановлення та запуск

1. Встановити необхідні бібліотеки:

    pip install -r requirements.txt

2. Запустити модульні тести для перевірки математичної коректності алгоритмів:

    python -m unittest discover -s tests -v

3. Виконати пакетну обробку зображень та генерацію звітів:

    python main.py
